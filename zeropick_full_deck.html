팀 소개

저희는 제로 식품 정보 제공 및 개인 맞춤 서비스를 개발한 ZeroPick 팀입니다. ZeroPick은 다양한 제로·저당 제품의 정보를 한곳에서 검색하고 분석할 수 있으며, 사용자의 취향과 알레르기 정보를 바탕으로 제품을 추천하고 여러 제품을 직접 비교할 수 있는 웹 서비스입니다.

  • 로그인 / 회원 관리
  • 카테고리 API

김아인

Backend
  • 상품 조회
  • 섭취 기록
  • 비교함 API

Access Token · Refresh Token 분리 구조

긴 수명의 토큰은 안전하게 감추고, 짧은 수명의 토큰만 매 요청에 명시적으로 전달하도록 설계했습니다.

Access Token
짧은 유효기간으로 보안 강화
  • JSON 응답 body로 전달 (쿠키 미사용)
  • API 요청 시 Authorization: Bearer 헤더에 포함
  • 유효기간 24시간
Refresh Token
긴 유효기간으로 로그인 유지
  • HttpOnly Cookie로 저장 (JS로 접근 불가)
  • 쿠키 경로를 /api/v1/auth로 제한
  • 유효기간 14일

수명이 긴 Refresh Token은 JavaScript가 접근할 수 없는 쿠키에 감추고, Access Token은 필요한 요청에만 명시적으로 실어 보안과 끊김 없는 로그인 경험을 함께 확보했습니다.

TokenService.java
public TokenPair reissue(String refreshToken) {
if (!StringUtils.hasText(refreshToken) || !jwtUtil.isValid(refreshToken)) {
throw new UnauthorizedException("리프레시 토큰이 유효하지 않습니다.");
}
String email = jwtUtil.extractEmail(refreshToken);
User user = userRepository.findByEmailAndDeletedAtIsNull(email)
.orElseThrow(() -> new UnauthorizedException("..."));
if (!refreshToken.equals(user.getRefreshToken())) { // DB 대조
throw new UnauthorizedException("...");
}
String newAccessToken = jwtUtil.generateToken(user.getEmail());
String newRefreshToken = jwtUtil.generateRefreshToken(user.getEmail());
user.updateRefreshToken(newRefreshToken); // 토큰 교체(Rotation)
return new TokenPair(user.getId(), newAccessToken, newRefreshToken);
}

취향 · 알레르기 기반 맞춤 추천

알레르기 · 비선호 성분 하드 필터 → 선호 카테고리 내 점수순 추천 → 부족분 전체 상품에서 보완 → 최종 추천 리스트

알레르기 · 비선호 성분이 포함된 상품은 후보에서 완전 제외(하드 필터)하고, 선호 카테고리 상품을 점수 높은 순으로 우선 추천합니다. 선호 카테고리 미설정 유저도 전체 상품 기준으로 추천되어 콜드스타트에 대응합니다.
